# Multi-monitor

## Panels everywhere

Open Vindue and a grid panel appears **on every display at once**, each sized
so its grid matches that display's shape. Drag on any panel to place the
target window on that display — whichever panel you release on wins.

[Shortcuts](./shortcuts) can belong to a specific display: press `3` and the
window flies to its saved display, even while you're looking at a different
one.

## Naming your displays

When several connected displays share a name (two identical monitors, say),
Vindue tells them apart by position — the same arrangement System Settings
shows:

- `DELL U2720Q (left)` / `DELL U2720Q (right)`
- `(middle)` for triplets
- `(left-to-right #N)` for four or more

These labels appear in the Settings dropdown and in error messages, and they
are recomputed every time Vindue applies something — so "left" always means
the display currently sitting in the left slot. Rearrange your displays and
the labels follow.

## Unplug, replug, reboot

macOS doesn't hand apps a permanent ID for displays, so Vindue matches them by
name and position, best effort. If a shortcut's saved display is missing when
it fires, Vindue falls back gracefully — a same-named display, then the
display currently in that position, then the one you're on — and the panel
footer tells you which it used. Nothing is ever lost; worst case the window
lands on the display in front of you.

Per shortcut you can also choose **Relative** instead of pinned: the shortcut
follows whichever panel you used, rather than a specific display.
